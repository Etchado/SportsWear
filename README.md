# SportsWear

A production-ready multi-brand sportswear e-commerce store built with React 19, Vite, Tailwind CSS, and Supabase.

## Tech Stack

- **Frontend:** React 19, Vite 8, React Router DOM v7
- **Styling:** Tailwind CSS 3, Motion (Framer Motion v12)
- **Backend:** Supabase (PostgreSQL + Auth)
- **State:** React Context API
- **i18n:** i18next (EN / AR + RTL)
- **Validation:** Zod
- **Deployment:** Vercel

## Getting Started

```bash
npm install
cp .env.example .env.local
# Fill in VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev
```
